# Interior Luxe Studio

A browser-based interior design concept with the Luxe theme from the B iteration. Explore room planning and 3D interior views.

## Run

Open `index.html` in a modern desktop browser. The original standalone HTML includes its scripts, styles and embedded assets. WebGL is required for 3D views.

## Scope

This is an interactive front-end prototype with sample data and some placeholder copy. Sign-in screens are demonstrations; use sample values rather than real credentials. No production backend is connected.

The supplied source folder contained only partial iteration updates, so this repository preserves the complete standalone version. To edit the application, edit its embedded HTML, styles and JavaScript directly. A modular source rebuild is not included.

## Validation

Embedded application JavaScript passed Node.js syntax checks. Interactive browser workflows and WebGL rendering remain unverified.
